# 🧩 Chapter 02: JavaScript Objects

Learn how JavaScript objects organize related information as key-value pairs.

## 🎯 Topics Covered

- **Managing properties:** reading, adding, updating, and deleting
- **Nested objects and object methods**
- The `this` keyword
- **Object utilities:** `Object.keys()`, `Object.values()`, and `Object.entries()`
- Iterating over objects
- **Destructuring, spread syntax, and `Object.freeze()`**
- Objects inside arrays

## 🚀 Run the Examples

Run this command from the repository root:

```bash
node Chapter_02/02_Objects.js
```
