# 📘 Chapter 01: JavaScript Arrays

Learn how to create, access, and work with JavaScript arrays through practical examples.

## 🎯 Topics Covered

- **Creating and updating** arrays
- **Adding and removing elements:** `push()`, `pop()`, `shift()`, and `unshift()`
- **Editing and copying:** `splice()` and `slice()`
- **Reversing, sorting, and iteration**
- **Array methods:** `forEach()`, `map()`, `filter()`, `reduce()`, `find()`, `some()`, and `every()`
- **Destructuring and spread syntax**

## 🚀 Run the Examples

Run this command from the repository root:

```bash
node Chapter_01/01_Array.js
```
