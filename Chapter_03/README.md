# 🌐 Chapter 03: Document Object Model (DOM)

The **Document Object Model (DOM)** represents an HTML document as a tree of objects that JavaScript can access and modify.

## 🎯 Chapter Overview

This chapter introduces the DOM and how it connects JavaScript with HTML documents.
